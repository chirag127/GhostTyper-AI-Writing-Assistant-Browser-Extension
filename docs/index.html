How it works

1

Install the extension

Download the release zip, unzip it, and load unpacked in Chrome (or compatible browser). No store required.

2

Start typing

GhostTyper detects your text fields automatically. After a short debounce (default 500ms), it fetches a suggestion from your provider.

3

Ghost text appears

The suggestion renders inline in grey — just like GitHub Copilot. Keep typing to dismiss or press Tab to accept instantly.

4

Choose your provider

Open Settings to switch provider, add an API key, or point GhostTyper at a custom OpenAI-compatible endpoint.

FAQ

Does GhostTyper work on all websites?

Yes. GhostTyper injects into standard input, textarea, and contenteditable fields on any site. A few sites (like password fields) are intentionally excluded. You can also add sites to your personal block list in Settings.

Is my text sent to anyone other than my chosen provider?

No. GhostTyper has no backend. The text before your cursor is sent directly from your browser to your chosen AI provider. There is no intermediate server. See Privacy Policy for full details.

How do I get an API key for Groq / Gemini / etc.?

Each provider has a free console. Visit console.groq.com, aistudio.google.com, cloud.cerebras.ai, openrouter.ai, or console.mistral.ai. Sign up free, generate an API key, and paste it in GhostTyper Settings.

Will it work with Pollinations forever for free?

Pollinations is a community-supported free AI inference service. GhostTyper uses it as the zero-config default. If it becomes unavailable, switch to any other provider in Settings.

Which browsers are supported?

Any Chromium-based browser that supports MV3: Chrome 109+, Edge 109+, Brave, Arc, Opera, Vivaldi. Firefox support is not yet available (MV3 API surface differs).
